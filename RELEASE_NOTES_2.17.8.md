# OF Downloader 2.17.8

- CLI nativa iOS creada desde cero para a-Shell.
- `of` es el comando principal; `of-ios` queda como alias.
- Menú equivalente para probar acceso, ver suscripciones y descargar perfiles o publicaciones.
- Importación automática del JSON desde la carpeta de a-Shell.
- Conserva los atajos `of URL` y `of probar-perfil NOMBRE` del CLI original.
